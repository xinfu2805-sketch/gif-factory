# GIF Factory project navigation

For children's bedtime read-aloud, English narrated picture books, bilingual
subtitled picture books, or parent-child reading videos, read
[`skills/compact-storybook/read-aloud-v1/WORKFLOW.md`](skills/compact-storybook/read-aloud-v1/WORKFLOW.md)
and its machine-readable contract before planning animation or duration.
Read [`skills/compact-storybook/SKILL.md`](skills/compact-storybook/SKILL.md)
for the parent workflow. The live handoff is [`CURRENT_WORKFLOW_STATUS.md`](CURRENT_WORKFLOW_STATUS.md).

For ordinary GIFs, stickers, posters, and short compact storybooks, keep
their existing routes in [`SKILL.md`](SKILL.md). Do not edit `main` directly;
work on a research branch and preserve the frozen GIF rendering algorithms.
