# GIF-FIRST-ACTION-R1｜有声绘本的角色 GIF 动作门禁

此流程是 XHS-READ-ALOUD-V1 中 **ART 后、ANIMATION 内** 的角色表演验收，不替代“故事 → 旁白 → 实测时间轴”的顺序。研究阶段可以单独制作未绑定正式时长的 GIF 动作样片，但不得将其当作正式视频。最终带声音的小红书作品仍输出 MP4，GIF 只负责逐页动作审核和可复用帧素材。

## 不再允许“环境动了，角色没动”

对每一个重要角色动作，先写：起因、情绪、首态、中态、末态、身体各部位的锚点、脚/地面接触点、道具交接状态。至少有可区分的首/中/末三个真实关键姿态；复杂动作追加关键姿态，不得只靠全图变焦/平移、背景星光云彩、整体弹跳或视频转 GIF 伪装。

素材要求：同一个角色身份，同一视角/画布，背景与角色分离，需要动的耳朵、头、眼、躯干分层；接触点与比例稳定。先产无声一次播放 GIF，首中末帧实际检查，再用同一帧源进入 MP4 有声合成。一次性剧情动作不无限循环到首态；需要循环的动作须另行标明用途。

### 《小兔子等月亮》试点

- A 失落：抬头期待 → 低头，双耳从耳根自然下垂 → 保持轻微失落。两脚不漂移。
- B 入睡：清醒 → 身体蜷起/前肢收拢 → 闭眼 → 自然呼吸末态。不能只有睡姿静态画面配星光。

## 真实 GIF 导出

准备排列好的真实同画布帧 `000.png`、`001.png`、`002.png`……。运行：

```bash
python3 scripts/export_storybook_gif.py PATH_TO_FRAMES out/action.gif --subject-box 210,400,360,650 --frame-ms 180 --last-hold-ms 800
```

导出器会检查至少3帧、固定尺寸、角色 ROI 前后变化、多个连续步长、GIF 实际解码帧数、无无限循环扩展，并提供哈希与 `.qa.json`。

重要：**角色 ROI 发生像素变化不是动作自然的证据**。导出器最多签发 `TECHNICAL_GIF_PASS`；`ACTION_PASS` 必须人工看完实际 GIF，审核表情、关节、身份一致、接触点与末态，没检查就继续 `BLOCKED`。

这个门禁不改 GIF Factory 现有贴纸、像素、普通动态海报、普通 compact-storybook 的导出格式，不修改冻结算法，也不代替 `VOICE_REVIEW`、`READ_ALOUD_PASS`、版权与发布许可。
